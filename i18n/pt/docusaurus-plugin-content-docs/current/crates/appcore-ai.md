# appcore-ai

:::caution Em breve
O `appcore-ai` está em desenvolvimento e **ainda não foi publicado**. No
momento, ele não está disponível no crates.io nem no docs.rs e não deve ser
usado como dependência.
:::

O `appcore-ai` é o crate planejado para suporte a IA no AppCore. Esta página
reserva seu lugar no catálogo enquanto a implementação e o contrato público são
finalizados.

A API pública, a fronteira de dependências, a versão, a MSRV, as instruções de
instalação e os exemplos serão adicionados quando o crate estiver pronto para a
release.
